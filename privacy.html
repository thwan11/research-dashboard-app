개인정보처리방침

research-dashboard · 시행일 2026-10-28

1. 무엇을 읽는가

사용자가 직접 로그인해 허용한 Google 계정에 대해 다음만 읽는다 (읽기 전용 권한 calendar.readonly, 로그인 확인용 openid·email):

  • 계정의 이메일 주소 (어느 계정인지 구분하는 용도)
  • 캘린더 목록 (이름, 색)
  • 사용자가 고른 캘린더의 일정 (제목, 시간, 장소)

2. 어디에 두는가

  • 모든 처리는 사용자 본인의 컴퓨터 안에서 일어난다. 별도 서버로 보내지 않는다.
  • 로그인 유지에 필요한 토큰은 사용자 컴퓨터의 설정 파일에만 저장한다 (본인만 읽을 수 있는 권한).
  • 일정 내용은 화면에 보여 주기 위해 잠시 메모리에 담아 둘 뿐, 따로 저장하지 않는다.

3. 누구와 공유하는가

누구와도 공유하거나 판매하지 않는다. 광고·분석 도구를 쓰지 않는다. Google API 에서 받은 정보의 사용은 Google API Services User Data Policy 의 Limited Use 요건을 따른다.

4. 권한 거두기

대시보드의 「연결 끊기」를 누르면 저장된 토큰을 지우고 Google 쪽 권한도 거둔다. Google 계정 → 타사 앱 접근에서도 언제든 거둘 수 있다.

English summary

research-dashboard runs only on its owner's computer. With read-only consent it reads the signed-in account's email address, calendar list and the events of calendars the owner selects, and displays them locally. Tokens are stored in a local config file readable only by the owner; event data is not stored or sent anywhere else. No data is shared, sold, or used for ads or analytics. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked from the dashboard ("연결 끊기") or at myaccount.google.com/permissions.
